# 玖柒廚房

為香港手機及電腦用戶製作嘅食譜網站，採用繁體中文及香港用語，綠橙色品牌視覺、香港明體標題、輕巧動態效果。

## 已包含

- Excel 原有 27 道精選食譜，保留產品關聯、材料及做法；新增 3 道獨立創新菜式及配圖。
- 依照實拍修正全部 7 道寬粉配圖嘅粗細同厚薄。菜式圖片為 AI 示意。
- 廚神打卡：拍照／揀相、菜名、可選心得、濾鏡及邊框、下載／手機分享、發布至共創菜品。
- 男女各 3 款廚師服：白色經典雙排扣、黑色現代斜襟、黃色短袖圍裙款。採用不同身形嘅插畫模特。相片裁切合成可自行調整位置及大小，並非擬真 AI 換臉。
- 收藏同已發布作品使用 D1 資料庫，完成嘅打卡相使用 R2 圖片儲存。原始人像只喺瀏覽器處理；發布時只傳送合成打卡相。
- 公開瀏覽毋須登入。收藏及發布需要會員身份；原有平台身份兼容保留。
- ESG 商城、客服及 WhatsApp 福利群暫時顯示「敬請期待」。

## 手機登記啟用

手機登記包含可選區號、六位短訊驗證碼、重發冷卻、伺服器限流、會員記錄及登入狀態。未配置短訊服務時會如實顯示尚未啟用，唔會假裝發送或接受測試驗證碼。

目前使用網站已有嘅 D1 及 R2，毋須另購資料庫或相片儲存。短訊需要另外開通 [Twilio Verify](https://www.twilio.com/en-us/verify/pricing)，按成功驗證及目的地短訊用量收費。到 [Twilio Console](https://console.twilio.com/) 建立 Verify Service、啟用 SMS，確認服務允許香港及打算支援嘅地區。試用帳戶通常只可發往已驗證號碼；正式對外使用需要升級帳戶及設定預算。

將以下三個值透過網站設定嘅伺服器環境變數加入，唔好放入前端、Git 或聊天訊息：

- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`（秘密值）
- `TWILIO_VERIFY_SERVICE_SID`

儲存設定後重新發布，先用自己嘅香港手機測試發碼、重發、錯碼、登入、跨裝置收藏，再開放會員登記。資料庫會自動建立所需資料表。短訊預設按電話地區決定語言，可於 Verify 服務設定繁體中文範本。現有限額：同一號碼每分鐘 1 次、每小時 5 次；同一 IP 每小時 15 次；全站每日 100 次。呢啲係首發保護值，有實際用量後再調整。

## 部署及開發

網站使用現有 Sites 託管，可設定公開連結，毋須另外搬去 Vercel。呢個交付係響應式網站；原生微信小程式封裝係另一步工作。

`npx tsc --noEmit` 驗證型別；`node --test tests/*.test.mjs` 驗證食譜、配圖、電話正規化及驗證碼資料限制。使用既有網站建置流程部署。D1 schema 喺 `db/schema.ts`，遷移檔案喺 `drizzle/`。

設計採用 Impeccable 嘅 bolder 及 craft-floor 指引；記錄見 `DESIGN.md`。自託管 Noto Serif CJK HK 字體及授權喺 `public/assets/fonts/`，生成圖片提示詞保留喺 `design/v2-image-provenance.json`。

## 第三版更新

已按用戶要求移除頁面上嘅食譜來源及配圖說明。來源資料及生成提示詞仍留喺原始資料內，便於維護。食譜詳情加入備料剔選、語義圖示、步驟完成狀態同動畫。打卡工作室提供三款版式、三款邊框、三款字體風格、三種點綴色，以及相片焦點同標題大小調整。

密碼登記係獨立於短訊嘅登入方式：登入名稱 + 密碼 + 公開稱呼。密碼以 bcrypt cost 12 雜湊及獨立隨機鹽儲存；登入憑證只以雜湊留喺資料庫，瀏覽器 cookie 設為 HttpOnly / Secure。名稱喺帳戶及共創作品顯示。會員建立及登入有限流；目前未提供自助重設密碼。密碼及手機帳戶暫時係獨立身份，唔會自動合併收藏。

訪客由共創入口進入時先顯示會員登記；成功後返回工作室。喺一般工作室製作咗打卡相後先登記，草稿、造型及版式狀態會保留，唔會自動發布。

### 外部訪問狀態

網站已設成 public，但用戶提供嘅手機截圖顯示 chatgpt.site 前面嘅 Cloudflare 安全層封鎖。應用程式本身無權修改平台 WAF；公開模式唔等於所有網絡必定可用。用戶已成功連接 Vercel。已建立 Vercel 公開入口，程式見 deployment/vercel-gateway；部署管理查詢目前被 Vercel 以團隊範圍權限不足拒絕，公開匿名訪問已確認被轉到 Vercel 登入頁，因此目前唔係可直接分享嘅公開網址。

如遷移至 Vercel：需要改成標準 Next.js 建置，將 D1/R2 存取轉成自有資料服務（例如 Supabase Postgres + Storage），遷移已儲存嘅會員、雜湊、收藏及圖片，加入部署環境值後測試註冊、登入、圖片上載同回程。唔可以只複製靜態首頁就當完成遷移。品牌商用網站應確認 Vercel Pro 方案及用量費用。

另一個可評估方案係喺現有 Sites 綁定自有網域：保留現有資料服務，但因未知道觸發封鎖嘅具體規則，唔能夠承諾換網域一定解決。用戶需提供已擁有或新購嘅網域並完成 DNS 驗證。

公開入口部署記錄：Vercel 建立回應為 INITIALIZING，deployment id dpl_ALpfYtbBWWFQRyrMFDWtUQLLHPR2，穩定 alias jiuqi-kitchen-tourisminvestors-projects.vercel.app。連接對該 scope 的管理讀取被 403 拒絕，未以其他憑證繞過。現有 Sites 第三版已成功發布。

公開訪問檢查結果：首頁同 /api/auth/status 均被 302 轉到 vercel.com/login。需由有權管理該專案的人喺 Settings → Deployment Protection 調整 Vercel Authentication，使正式對外網域可匿名存取。現有連接欠缺 scope 權限，未使用保護繞過連結或 token。
