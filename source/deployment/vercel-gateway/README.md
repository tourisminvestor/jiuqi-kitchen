# 玖柒廚房公開入口

Vercel Node 入口將同源頁面、資產及 API 請求送至現有公開網站。會員及圖片保留於原有 D1 / R2；瀏覽器只使用 Vercel 網域，登入 cookie 亦只屬於該網域。沒有複製或公開平台身份憑證。

POST 要求本入口同源 Origin。只轉發本站會員 cookie，唔接受客戶端聲稱嘅平台身份／IP；回應內壓縮長度及內容編碼由代理重新處理。平台登入入口唔對外使用，訪客使用本站密碼帳戶。

限制：呢個入口仍依賴現有後端。上游故障或拒絕 Vercel 伺服器請求時亦會不可用，必須實際檢查後先分享。上游按 IP 限流會將入口流量視作同一來源；小規模試用後，如需更大量註冊，應接入可信的端到端訪客限流或遷移獨立資料服務。Vercel 函數另有请求大小限制，手機發布相片需要壓縮到 4 MB 以下。
